# Changelog

All notable changes to the public StreamCast release are documented here.

## 1.0.0 - 2026-09-25

- Released metadata and temporal coordinates for 470 source livestreams.
- Released 1,421 bilingual four-choice benchmark questions.
- Released offline preprocessing and shared evaluation utilities.
- Added the Data Card, source-media policy, identity-minimization policy,
  licensing scope, and takedown procedure.
- All 470 source entries are included in this release; no entries have been
  retired or replaced.
